# 🇭🇰🇲🇴 港澳跨境交通与支付羊毛（深港/广珠跨境必备）

身处深圳和广州，去香港、澳门购物游玩或跨境通勤非常频繁。善用跨境支付汇率券与交通优惠，每次过关都能省下几十到上百元。

---

## 一、 深港/穗港交通省钱攻略

### 1. 深圳过关香港：怎样坐车最省钱？
- **港铁（MTR）东铁线省钱技巧**：
  - **深圳湾口岸 / 莲塘口岸巴士 vs 罗湖/福田港铁**：如果去屯门、元朗、尖沙咀、旺角，从**深圳湾口岸**坐 B2P / B3X 城巴或跨境直通大巴（如环岛中港通、永东巴士，在美团/飞猪/抖音提前团购双程票仅需 **60～80 元往返**），比从罗湖/福田坐港铁（单程就要约 45～55 港币）便宜近一半！
  - **莲塘口岸（香园围）**：乘坐城巴 B7 / B8 或九巴 B9，票价仅需 **10～20 港币左右**，是目前深港陆路口岸中接驳交通成本最低的选择之一。
- **港铁都会票 / 游客全日通 / 微信支付宝乘车码优惠**：
  - 打开 **支付宝 App** 或 **微信** 搜索 `香港乘车码`，经常可领 **港铁/巴士 2～5 元立减券** 或 1 分钱购香港交通优惠包。

### 2. 广州往返香港/澳门：大巴 vs 高铁/城轨
- **广州 <-> 香港**：
  - 高铁（广州东/广州南 -> 香港西九龙）票价约 215 元/单程；
  - 若追求极致性价比，可在 **美团 / 抖音 / 环岛中港通 / 中旅巴士** 小程序购买广州市区（天河城、以太广场、海珠广场等）直达香港旺角/尖沙咀/铜锣湾的**跨境大巴往返套票**，促销售价经常低至 **110～150 元/往返**！
- **广州 <-> 澳门（珠海拱北/横琴）**：
  - 除广珠城际铁路外，广州市区有多条直达珠海拱北口岸/横琴口岸的旅游大巴（关注 `如约城际` 或各大巴士小程序），单程票价常低至 **25～39.9 元**，比城轨便宜一半。

## 二、 跨境支付汇率与消费立减羊毛

去港澳消费前，先花 2 分钟在以下 App 把所有汇率券和红包领完：

1. **支付宝（Alipay）出境惠**
   - 切换左上角城市为 **“香港”** 或 **“澳门”** -> 点击“惠出境”。
   - 必领：**超优汇率券（黑钻汇率）**、**笔笔减红包**、**屈臣氏/万宁/莎莎/百佳/7-11 专属满减券**。
2. **微信支付（WeChat Pay）跨境游礼包**
   - 微信搜索 `微信香港优惠` 或 `游港澳` 小程序，每周可领汇率优惠券和满 100 减 10 等商家券。
3. **云闪付 App “港澳精彩游”**
   - 搜索 `香港优惠` 或 `汇率优惠`，提前报名名下银联卡（62开头）的**境外消费笔笔返现（1%～10% 不等）**活动，在港澳刷银联卡或扫银联二维码自动触发。
4. **八达通 App（旅客版 / 手机八达通）**
   - iPhone 用户可直接在 Wallet 开通八达通，或下载 `Octopus for Tourists` App，配合银联/支付宝充值偶尔有满额立减活动。
