# 🏙️ 深圳 & 广州 薅羊毛与省钱全攻略 (GZ & SZ Deals Guide)

一份专为在**深圳（Shenzhen）**与**广州（Guangzhou）**生活、工作、求学或游玩的朋友整理的**全方位“薅羊毛”与省钱实操指南**。涵盖政府消费券与国补、公共交通出行、商超晚间打折与剩菜盲盒、公共文体与市民夜校、银行及工会隐藏福利、社康医疗与特定人群优待六大板块。

---

## 📌 笔记收录与编写要求（三大基本准则）

本指南所有条目在新增与维护时均严格遵循以下三条标准：

1. **要没有过期（时效有效）**：仅收录当前仍在正常执行的政策补贴、常设优惠渠道与商超打折机制，剔除已停办或过期的历史活动。
2. **要可行（真实可实操）**：每项羊毛必须附带具体的办理入口（小程序/App/公众号）与清晰的操作步骤，普通人按图索骥即可走通，拒绝门槛极高或纯噱头项目。
3. **要有用而不是多余（真省钱、不凑数）**：必须能带来实打实的折扣、补贴或免费权益，不把常规政务常识或动用个人自有资金当成羊毛（比如**提取自己的住房公积金**属于支取个人固有资产，并非额外省钱福利，不予收录）。

## ⏰ 每日/每周/每月黄金“薅羊毛”时间轴

- **每天 09:00 / 10:00 / 12:00**：各区政府消费券、文旅券、体育场馆免费号源开抢高发时段。
- **每天 16:00 - 18:00**：烘焙店、轻食店“剩菜盲盒”在小程序集中上架。
- **每天 19:30 - 20:30**：盒马、沃尔玛、永旺（AEON）、钱大妈开启第一轮晚间黄标打折（7~8折）。
- **每天 21:00 以后**：盒马、永旺开启熟食、寿司、烘焙深度清仓（5~6折或买一送一）。
- **每周二**：永旺（AEON）周二会员日与均一价特惠；塔斯汀/部分餐饮周二会员日。
- **每周三**：招商银行掌上生活“周三5折美食日”；达美乐比萨周二周三比萨7折。
- **每周四**：肯德基疯狂星期四；部分茶饮品牌会员日。
- **每年 3月 & 9月**：广深各区文化馆“市民夜校”春季班、秋季班集中报名抢课。
